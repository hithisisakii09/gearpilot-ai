## Scope and safeguards

Phase 4.0 improves editorial transparency and buying-guide education and adds validation for a future, explicitly authorized Branch/CJ evidence intake. It does not alter catalog or affiliate registry data, persist intake, create tracking links, enable analytics, publish a real offer, merge, or deploy.

The intake schema validates shape, source host, date order, market, host syntax, restrictions, and safe references. A passing validator is not an approval determination; official proof and a separate authorized human review remain mandatory.
