## Onboarding checklist

1. Locate the merchant's official application or authorized-network page manually; record its URL only after verification.
2. Review current terms for permitted content, regions, mandatory disclosure, attribution, coupon rules, and approved-domain destinations.
3. Submit an application only with an authorized human owner. This project never submits applications automatically.
4. Store approval confirmation and tracking ID outside Git. Add a safe `credential-ref:` only after access controls exist.
5. Record the evidence reference/date, program/network name, US eligibility, and exact approved destination domains.
6. Add a specific verified product offer with fresh price/stock evidence. Do not attach an affiliate URL to a demo or partially verified record.
7. Run all validation/tests, manually verify the rendered link and disclosure, and obtain editorial/legal approval before merge or deploy.
