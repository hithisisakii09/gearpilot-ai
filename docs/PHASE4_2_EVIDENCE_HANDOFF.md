# Phase 4.2 human evidence handoff

## Collection procedure

1. A real researcher opens the official US manufacturer page in an ordinary browser. Do not bypass an interstitial, CAPTCHA, login, or other access restriction.
2. Select an actually purchasable frame, desktop size/material/finish, accessories, and controls. Record the displayed SKU or unambiguous exact variant identifier.
3. Capture manufacturer-sourced identity, dimensions, adjustment range (including whether the desktop is included), lift capacity, and current warranty terms applicable to that variant.
4. Record the source URL and exact UTC time of observation for each fact. For price, shipping, and stock, inspect the selected configuration and destination-specific cart/checkout summary before purchase; do not purchase.
5. Check return terms for the exact seller/market and record exclusions, return window, restocking conditions, and shipping responsibility. Leave any unconfirmed term UNKNOWN.
6. Submit evidence through the existing observation workflow with the collector’s real name. An authorized reviewer who is a different human independently checks configuration identity, source, timestamp, and claims.
7. Keep observation approval separate from product verification, offer eligibility, owner publication authorization, and affiliate approval.

## Safe evidence artifacts

- Structured observation containing only product/offer IDs, exact configuration/options, source URLs, fact values, UTC timestamps, and evidence notes.
- Redacted screenshot is supplementary support, not a substitute for structured facts and source provenance. Remove account names, addresses, order identifiers, payment/tax data, browser tokens, and other personal data. Never commit unredacted checkout/account screenshots.
- No collector or reviewer identity is prefilled in this report. Use genuine authorized identities only.
- Do not write to or approve either historical Vari observation as part of this handoff.
