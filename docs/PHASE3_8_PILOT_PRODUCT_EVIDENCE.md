## Required human confirmation before an observation

For either model, a collector must:

1. Select the US storefront and an exact purchasable variant, including desktop dimensions/material/finish, frame color/type, any required options, and visible SKU or stable variant identifier.
2. Record the canonical product/configurator URL and, if policy evidence comes from separate official pages, each separate policy URL.
3. Capture the page's price and currency, promotion conditions, mandatory shipping/free-shipping eligibility, and explicit stock state. If any fact is hidden, region-dependent, or only visible in checkout, leave it unknown; do not complete a purchase.
4. Record the official specification source for that exact variant and applicable warranty and return terms.
5. Capture a real UTC ISO-8601 `observedAt` at the time each fact is inspected, plus relevant page text or permitted evidence notes. The page access date above is not a substitute.
6. Supply the collector's real name. A different authorized human must independently review. No identity has been supplied or invented in this phase.
