## Application and code coverage

The site has no paid-search, direct-link advertising, logo placement, or active Branch link workflow in this release. The affiliate resolver gates outbound affiliate destinations on verified eligible product/offer records, approved program status, and allowlisted destinations. Commission rates do not enter the ranking calculation.

There is no product feature that can enforce search-ad bidding or copy behavior outside the application. No additional policy-specific runtime test or automation is justified while no program is approved and no such campaign is configured. Operational controls remain owner responsibilities: retain current terms securely, review every promotional channel against them, use only authorized creative, and prohibit promotion until Branch approval is documented.
